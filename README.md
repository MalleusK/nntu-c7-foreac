# Лабораторные работы по курсу «Основы радиоэлектроники и связи»

Репозиторий содержит материалы, расчетные модули и отчеты по лабораторным работам кафедры КТПП ИРИТ НГТУ им. Р.Е. Алексеева (направление 11.03.03 «Конструирование и технология электронных средств»).

Каждая лабораторная работа оформляется в виде типового отчета на **Typst** по университетскому ГОСТ-шаблону, а все расчеты, моделирование и генерация графиков автоматизированы на **Python** в среде **Pixi**.

---

## Требования и подготовка окружения

1. **Клонирование с подмодулями (включая шаблон `nntu-typst`):**
   ```bash
   git clone --recurse-submodules <url>
   # или в уже склонированном репозитории:
   git submodule update --init --recursive
   ```
2. **[Pixi](https://pixi.sh)** — пакетный менеджер, управляющий версией Python и библиотеками (`numpy`, `matplotlib`, `scipy`, `sympy`).
3. **[Typst](https://typst.app)** и расширение **Tinymist** в VS Code — для компиляции и просмотра отчетов.

Установка всех зависимостей проекта выполняется одной командой:

```bash
pixi install
```

---

## Запуск расчетов через Pixi

Все скрипты запускаются из корня репозитория через задачи `pixi run`. Имена задач структурированы по номеру лабораторной работы.

### Лабораторная работа №1

- **Запустить всё сразу (все задания по порядку):**
  ```bash
  pixi run lab1
  ```
- **Запустить конкретное задание:**
  ```bash
  pixi run lab1-task1   # Задание 1: равновероятный источник и шифр Цезаря
  pixi run lab1-task2   # Задание 2: частоты и энтропия английского текста
  pixi run lab1-task3   # Задание 3: частоты, энтропия и сжатие русского текста
  ```

---

## Сборка отчетов (Typst)

Отчеты ссылаются на шаблоны через `labs/common.typ` (использует подмодуль `nntu-typst`).

### В VS Code:

Достаточно открыть файл отчета (например, `labs/1_analysis-of-entropy/1_analysis-of-entropy.typ`). Расширение **Tinymist Typst** автоматически отрендерит превью и соберет PDF при сохранении (параметры передаются через настройки `.vscode/settings.json`).

### Через консоль (с передачей номера группы):

Чтобы в титульный лист и штамп подставился номер учебной группы:

```bash
typst compile labs/1_analysis-of-entropy/1_analysis-of-entropy.typ
```

## Лабораторные работы

### ЛР 1. Исследование энтропии, избыточности и сжатия данных (`1_analysis-of-entropy`)

- **Задание 1 (`task1.py`):**
  - Генерация равномерного псевдослучайного ASCII-файла ($N = 100\,000$, буквы латиницы `a`–`z`).
  - Шифрование моноалфавитным шифром Цезаря ($k = 3$).
  - Экспериментальное подтверждение инвариантности энтропии ($H = 4.7001$ бит/симв.) и предела Шеннона ($K_{\text{сжат}} \approx 1.57$).
  - Артефакты: график `task1_uniform_caesar_hist.svg`, таблица `task1_uniform_frequencies.csv`.

- **Задание 2 (`task2.py`):**
  - Статистический анализ английского текста романа «Война и мир» ($N = 2\,512\,966$).
  - Расчет энтропии ($H_{\text{en}} = 4.1653$ бит/симв.) и избыточности первого порядка ($R \approx 11.38\%$).
  - Оценка роли контекстной избыточности и словарного сжатия LZ77 ($K_{\text{сжат}} = 2.693$).
  - Артефакты: график `task2_en_letter_distribution.svg`, таблица `task2_en_frequencies.csv`.

- **Задание 3 (`task3.py`):**
  - Статистический анализ русского текста романа «Война и мир» ($N = 1\,485\,071$, $m = 32$).
  - Расчет энтропии ($H_{\text{ru}} = 4.4666$ бит/симв.) и избыточности ($R \approx 10.67\%$).
  - Анализ влияния двухбайтовой кодировки UTF-8 на степень сжатия ($K_{\text{сжат}} = 3.799$).
  - Артефакты: график `task3_ru_letter_distribution.svg`, таблица `task3_ru_frequencies.csv`.
